# Architecture Decision Record (ADR)

# ADR-004: Tailwind CSS utility-first Styling

- **Estado:** Aprobado
- **Fecha:** 2026-07-12
- **Autor:** Antigravity (AI Architect)

---

# 1. Contexto (Context)
El frontend de Campus Arena requiere un diseño dinámico, altamente responsivo, premium y coherente con el Design System. Para agilizar el maquetado sin crear archivos CSS gigantescos o acoplar estilos en clases complejas y hojas de estilo separadas, necesitamos un motor de estilos ágil y optimizado.

---

# 2. Decisión (Decision)
Hemos elegido **Tailwind CSS** como el framework de diseño y utilidades CSS principal para el desarrollo del frontend de Campus Arena.

---

# 3. Justificación (Justification)

1. **Desarrollo Rápido:** Evita saltar constantemente entre el archivo TSX del componente y la hoja de estilos CSS. Las clases se declaran inline y son autodeclarativas.
2. **Cero Hojas de Estilos Gigantes:** Tailwind purga (elimina) las clases no utilizadas durante la compilación, generando un archivo CSS final optimizado de unos pocos kilobytes, acelerando el tiempo de carga móvil de la landing y dashboards.
3. **Consistencia de Tokens de Diseño:** A través del archivo `tailwind.config.js`, podemos inyectar nuestros tokens de color, espaciados y bordes definidos de forma centralizada.
4. **Acoplamiento perfecto con Componentes React y shadcn/ui:** shadcn/ui está construido de manera nativa sobre Tailwind CSS, facilitando la copia y extensión de controles accesibles mediante clases de utilidad.

---

# 4. Consecuencias (Consequences)

### Positivas
- Estilizado veloz y adaptable directamente en los componentes.
- Cargas del lado del cliente optimizadas.
- Configuración de tokens de diseño centralizada y replicable.

### Negativas
- Legibilidad inicial de la estructura HTML/TSX reducida ante componentes complejos que requieren decenas de clases de Tailwind (mitigable agrupando estilos mediante utilidades como `clsx` o `tailwind-merge`).
