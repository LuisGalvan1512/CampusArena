# Architecture Decision Record (ADR)

# ADR-003: JWT and Refresh Token Authentication

- **Estado:** Aprobado
- **Fecha:** 2026-07-12
- **Autor:** Antigravity (AI Architect)

---

# 1. Contexto (Context)
Campus Arena es un sistema SaaS que gestiona torneos e inscripciones de estudiantes en tiempo real. La API debe ser stateless para facilitar el escalamiento en la nube (sin persistencia de sesión pegajosa en el servidor). Al mismo tiempo, la autenticación debe ser segura frente a ataques comunes como Cross-Site Scripting (XSS) y Cross-Site Request Forgery (CSRF).

---

# 2. Decisión (Decision)
Hemos elegido implementar una estrategia de autenticación basada en **JSON Web Tokens (JWT)** con rotación de **Refresh Tokens** y cookies seguras.

---

# 3. Justificación (Justification)

1. **Stateless API:** El uso de JWT permite que el servidor web valide la identidad del usuario sin consultar la base de datos en cada petición HTTP ordinaria (descifrando la firma del token).
2. **Mitigación de XSS (Refresh Token en Cookie httpOnly):** 
   - El *Access Token* es de corta duración (15 minutos) y se almacena en la memoria de la aplicación frontend.
   - El *Refresh Token* es de larga duración (7 días) y se almacena en una cookie del navegador configurada con las banderas `httpOnly: true`, `secure: true` y `sameSite: strict`. Esto evita que scripts JS maliciosos accedan al token persistente.
3. **Mesa de Ayuda para Sesiones (Session Invalidation):** Guardaremos un hash de la sesión activa en el esquema `auth` de Postgres (`Session` y `RefreshToken`), permitiendo la invalidación inmediata de sesiones si un usuario lo solicita o ante un inicio sospechoso.

---

# 4. Consecuencias (Consequences)

### Positivas
- Escalabilidad horizontal sencilla de la API NestJS.
- Alta seguridad en navegadores modernos contra robo de sesiones.
- Control de cierre de sesión centralizado.

### Negativas
- Lógica de cliente en frontend ligeramente más compleja al requerir interceptores de Axios/Fetch para refrescar el token de acceso de manera asíncrona y transparente para el usuario.
