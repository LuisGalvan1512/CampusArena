# Architecture Decision Record (ADR)

# ADR-008: shadcn/ui Component Library

- **Estado:** Aprobado
- **Fecha:** 2026-07-12
- **Autor:** Antigravity (AI Architect)

---

# 1. Contexto (Context)
Para construir las interfaces de Campus Arena con calidad premium, necesitamos una biblioteca de componentes interactivos (botones, modales, menús, dropdowns) que sean completamente personalizables, responsivos, cumplan con las especificaciones de accesibilidad WCAG AA y se integren fluidamente con Tailwind CSS.

---

# 2. Decisión (Decision)
Hemos elegido adoptar **shadcn/ui** (basado en Radix UI Primitives y Tailwind) como la biblioteca base para el paquete `@campus-arena/ui`.

---

# 3. Justificación (Justification)

1. **Código en el Repositorio (No es dependencia NPM):** A diferencia de Material UI o Chakra UI, shadcn/ui copia el código del componente directamente en nuestra carpeta `@campus-arena/ui`. Esto nos da control del 100% sobre el comportamiento y los estilos de cada elemento, permitiendo adaptarlos libremente a nuestro Design System.
2. **Accesibilidad Nativa (Radix UI):** Los componentes primarios están construidos sobre Radix UI, que incluye soporte para navegación por teclado, roles ARIA y foco visible de manera nativa.
3. **Integración con Tailwind:** El diseño se modifica puramente con clases de Tailwind, permitiendo acoplar directamente nuestros Design Tokens definidos.

---

# 4. Consecuencias (Consequences)

### Positivas
- Control total y personalización sin límites del diseño de componentes.
- Accesibilidad de primer nivel por defecto.
- Cero bloated bundle size (solo importamos y compilamos lo que realmente usamos).

### Negativas
- Mayor cantidad de archivos de componentes de UI residiendo directamente en nuestro repositorio (paquete `@campus-arena/ui`).
- Actualizaciones de la biblioteca deben realizarse de forma manual o selectiva, en lugar de un simple `npm update`.
